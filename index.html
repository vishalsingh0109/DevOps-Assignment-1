📌 Project Overview

This project implements a containerized application using FastAPI and PostgreSQL. The backend handles API logic while the database ensures persistent storage. Docker is used to package both services, and Docker Compose orchestrates them.

The architecture ensures scalability, isolation, and easy deployment across systems.

🧠 DevOps Concepts

  • Containerization using Docker
  • Multi-container architecture
  • Persistent volumes
  • Service networking

Client → FastAPI → PostgreSQL
